# LeadHarbor 设计系统

## 设计方向

LeadHarbor 采用 Apple-inspired 的「克制、清晰、亲和」界面语言：让复杂的线索数据保持轻盈，让每一次跟进都能自然发生。这里借鉴 Apple 的设计原则，不使用 Apple 商标、专属图形或仿制系统界面。

## 设计原则

- **清晰优先**：一个页面只保留一个主要任务；标题、辅助说明和行动按钮形成明确层级。
- **内容优先**：使用大面积留白、细边框和低对比阴影，减少视觉噪音。
- **渐进披露**：概览展示决策所需信息，详情和高级筛选按需出现。
- **可信反馈**：采集、加载、空状态和错误状态都要给出即时、可理解的反馈。
- **触控友好**：交互元素最小点击区域 32px，移动端布局不依赖悬停。

## 颜色令牌

| Token | Value | 用途 |
| --- | --- | --- |
| `--ink` | `#1D1D1F` | 主要文字 |
| `--muted` | `#86868B` | 次要文字 |
| `--soft` | `#F5F5F7` | 页面与输入背景 |
| `--line` | `#E7E7EA` | 分割线和边框 |
| `--blue` | `#0071E3` | 主要操作、链接、数据主色 |
| `--purple` | `#7357D8` | AI、智能推荐 |
| `--green` | `#1F9D68` | 成功、增长、已认证 |
| `--orange` | `#EA8B2C` | 需要关注的辅助指标 |

## 排版

- UI 字体：`Manrope`，回退到 `-apple-system` / `PingFang SC`。
- 数字、日期、域名：`DM Mono`，用于快速扫描和技术信息。
- 页面标题：31px / 700；模块标题：17px / 600；正文：11–13px。
- 字距整体偏紧，避免运营后台的视觉膨胀。

## 组件规范

- **按钮**：主按钮使用 LeadHarbor 蓝色，圆角 9px，最小高度 38px；次要动作使用无背景文字按钮。
- **卡片**：白色背景、1px `--line` 边框、13px 圆角；不使用厚重投影。
- **状态标签**：使用低饱和背景和深色文字，不仅依赖颜色传达状态。
- **表格**：表头使用等宽小字；行高保持宽松；hover 只改变背景，不移动布局。
- **弹窗**：背景增加 8px 模糊；内容卡片最大宽度 400px；关闭始终可见。
- **图标**：使用 `lucide-react`，默认 16–18px、1.9px 描边，图标只辅助文字，不替代关键标签。

## 响应式断点

- `640px`：单列内容、隐藏桌面侧边栏、表格允许横向滚动。
- `1000px`：侧边栏折叠为图标栏、指标卡片两列。
- 桌面内容最大宽度 `1330px`，页面横向内边距 `43px`。
